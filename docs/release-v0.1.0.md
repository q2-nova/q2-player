# Q2 Nova v0.1.0

This release is for the Shanling Q2 running stock V1.32. The installed device
reports V0.10. Start with the [installation, first listen and stock recovery
guide](install.md).

Q2 Nova provides a wheel-controlled player for music and audiobooks, including
files on your microSD card. Navidrome and Audiobookshelf are optional.

Get the installable `update.tar` and `SHA256SUMS` from the
[stable release](https://github.com/q2-nova/q2-player/releases/tag/v0.1.0)
when published. The release also provides the corresponding player source,
radio source and relink materials, debug symbols and the build receipt for the
download. `player-source.tar.gz` includes the libopenaptx license and relink
instructions. `stock-radio-source.tar.gz` contains the Wi-Fi driver and tools
sources, notices and build instructions. The stock image includes the pinned
RTL8733BS Bluetooth controller firmware and its provenance notice.

The [matching Q2 OS release](https://github.com/q2-nova/q2-os/releases/tag/v0.1.0-rc.5)
provides Buildroot corresponding source and notices in
`buildroot-legal-info.tar.gz`, as well as the matching kernel source references.
Keep the Shanling V1.32 ZIP and a card reader available before installing.
