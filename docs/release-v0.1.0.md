# Q2 Nova v0.1.0

This release is for the Shanling Q2 running stock V1.32. The installed device
reports V0.10. Start with the [installation, first listen and stock recovery
guide](install.md).

Q2 Nova provides a wheel-controlled player for music and audiobooks, including
files on your microSD card. Navidrome and Audiobookshelf are optional.

Get the installable `update.tar` and `SHA256SUMS` from the
[stable release](https://github.com/q2-nova/q2-player/releases/tag/v0.1.0)
when published. The release also provides the corresponding player source,
radio source and relink materials, debug symbols and the build receipt for the
download. Keep the Shanling V1.32 ZIP and a card reader available before
installing.
