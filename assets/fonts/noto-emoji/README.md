# Noto Emoji (monochrome), regular weight

Fallback glyphs for emoji in titles and playlist names.
Source: `https://github.com/google/fonts/raw/main/ofl/notoemoji/NotoEmoji%5Bwght%5D.ttf`
(variable font, SHA256 `de6c18832938afc99caf132b39d6a30a19bac7f2e812e28db2535b4608d27551`), licensed under the SIL Open Font
License 1.1 (`OFL.txt`). Instanced at wght 400 with fontTools
(`instancer.instantiateVariableFont(font, {"wght": 400})`, variation
tables dropped): 1,489 codepoints, 886,564 bytes. The app loads it as its
last fallback font, so Latin text and its speed are unchanged.
